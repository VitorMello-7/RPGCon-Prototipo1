Esse repositório faz parte do trabalho de TCC Imteligência Artificial e a gamificação do aprendizado.

A ideia é utilizar IA como assistente de código para desenvolver um jogo capaz de apoiar estudantes em futuras provas.

Estou utilizando alguns conceitos de grandes profissiobnais de desenvolvimento, como Matt Pocock e o conceito de grill-me, além de Fabio Akita.

Nesse protótipo estou apenas testando o desenvolvimento com apoio do agente Claude Opus 5, mas a ideia é escalar cada vez mais o poder para chegar num produto final de qualidade considerável.
